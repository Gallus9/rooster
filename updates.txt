6## [2025-01-29] Photo Upload System - Phase 1: Core Service & UI Components
- **MAJOR FEATURE**: Implemented foundational Photo Upload System including core service logic, UI components for photo selection and progress display, and initial offline queueing capabilities.

- **`PhotoUploadService.kt` Implementation**:
  - **Core Upload Logic**: Handles enqueuing, processing, and basic retry mechanisms for photo uploads.
  - **Image Preparation**: Integrates with `PerformanceOptimization.kt`'s `getCompressedImageBytes` utility for network-aware image compression before upload.
  - **Offline Queueing (Initial)**:
    - `SerializablePhotoUploadRequest`: Data class for serializing upload requests to disk (JSON via Gson).
    - Saves pending/failed requests to a local cache directory (`offline_photo_queue`).
    - Loads and attempts to resume queued uploads on service initialization.
    - Updates disk queue on status changes (progress, completion, failure).
  - **Progress Reporting**: Emits `UploadResult` via a `SharedFlow` to update UI on status and progress.
    - Uses blocking `ParseFile.save()` on IO dispatcher for simplicity in current phase; granular progress callback is a future enhancement.
  - **Target Object Linking**: Basic implementation to link successfully uploaded `ParseFile` to a specified `targetParseObject` and `targetField`.
    - Includes `UploadStatus.LINKING_FAILED` for cases where upload succeeds but linking fails.
  - **Cancellation**: Basic support for cancelling active uploads via `Job.cancel()`.
  - **Error Handling**: Manages upload failures, retries (up to 3 times with exponential backoff), and logs errors.

- **Photo Handling UI Components (`PhotoUploadComponents.kt`)**:
  - **`PhotoPickerDialog`**: Dialog for users to choose between gallery and camera.
    - Includes camera permission handling using Accompanist Permissions.
  - **`PhotoPreviewWithEdit`**: Dialog for previewing selected image (actual editing features are placeholders).
  - **`UploadProgressIndicator`**: Composable `Card` to display individual upload status, progress (simulated for now, then 100% on completion), error messages, and retry/cancel actions.
  - **`PhotoGridDisplay`**: `LazyVerticalGrid` to show multiple selected photo URIs with an "Add Photo" button.
  - **`PhotoUriHelper`**: Uses `FileProvider` for creating Uris for camera-captured photos (requires Manifest and XML setup).
  - **`PhotoUploadComponentsDemoScreen`**: Example screen to test and demonstrate the UI components and their interaction with `PhotoUploadService`.

- **FileProvider Setup**:
  - Added `<provider>` declaration for `androidx.core.content.FileProvider` in `AndroidManifest.xml`.
  - Created `res/xml/file_paths.xml` to define sharable paths (cache and external Pictures directory).
  - Added `<uses-permission android:name="android.permission.CAMERA" />` and `<uses-feature android:name="android.hardware.camera" android:required="false" />` to `AndroidManifest.xml`.

- **Enum Centralization & Build Fixes**:
  - **`AppEnums.kt`**: Created to be the single source of truth for `NetworkQualityLevel` and `ImageCompressionLevel` enums, resolving previous redeclaration errors.
  - **Dependency Management**: Added `com.google.accompanist:accompanist-permissions` and ensured `com.google.code.gson:gson` is correctly configured.
  - **Import Resolution**: Corrected imports for Gson, TypeToken, and Accompanist Permissions across relevant files.
