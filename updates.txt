## [2025-05-23] MCP Servers Integration & AI-Driven Workflow Guidance

### MCP Server Integration
- Integrated multiple Model Context Protocol (MCP) servers in `.config/github-copilot/intellij/mcp.json` to enhance development:
    - Playwright MCP: Browser/UI automation and testing
    - Context7 MCP: Natural language to code/UI generation
    - Awesome Linters: Curated linter/code quality reference
    - Sequential Thinking MCP: Step-by-step debugging and structured problem solving
    - Memory Bank MCP: Store/retrieve code, logs, and project memory
    - Steel Puppeteer MCP: Browser/emulator automation and screenshotting
    - Knowledge Graph Memory MCP: Persistent memory and relationship management
    - MCP Compass: Discovery and recommendation of MCP servers
    - DuckDuckGo Search MCP: Web search for documentation and solutions

### How to Use MCPs in Rooster App Development
- **Fix Build Errors**: Use context7 and sequential-thinking MCPs to generate/fix Jetpack Compose code and debug errors in files like `MainActivity.kt`.
- **Preview UI**: Use @Preview annotations in Compose, and automate emulator UI tests/screenshots with playwright or steel-puppeteer MCPs.
- **Lint and Format**: Reference awesome-linters and use tools like ktlint for code quality.
- **Store Progress**: Use memory-bank MCP to archive fixed code and build logs for future reference.
- **Validate Data**: Use Back4App dashboard for Parse data, and knowledge-graph-memory MCP for lineage/traceability previews.
- **Find Documentation**: Use duckduckgo-search MCP to quickly search for solutions to errors or implementation questions.
- **Get Recommendations**: Use mcp-compass MCP to discover the best MCP for a given task (e.g., UI prototyping, debugging).

### Example Prompts for AI Agents
- Generate/fix Compose code: `context7` MCP prompt for MainActivity.kt with BottomNavigation and navigation.
- Automate UI tests: `playwright` or `steel-puppeteer` MCP prompt to click tabs and screenshot screens.
- Lint code: Use `ktlint` as referenced by awesome-linters.
- Debug errors: `sequential-thinking` MCP prompt for stepwise build error resolution.
- Store/retrieve code: `memory-bank` MCP prompt to save MainActivity.kt and logs.
- Preview data relationships: `knowledge-graph-memory` MCP prompt for fowl lineage.
- Search for docs: `duckduckgo-search` MCP prompt for Compose navigation errors.
- Get tool recommendations: `mcp-compass` MCP prompt for UI or debugging tasks.
